# 📱 ProtectIt – Mobile Application

ProtectIt is a mobile application developed to help users identify, avoid, and respond to online threats such as phishing links, fake websites, and digital scams. The app focuses on improving user awareness and providing practical tools to enhance personal cybersecurity, especially for non-technical users.

---

## 🎯 Project Objectives

* To raise awareness about common online threats and scams
* To help users verify links and online content before interacting with them
* To provide basic cybersecurity guidance in a simple and user-friendly manner
* To reduce the risk of users falling victim to online fraud

---

## 🛠️ Key Features

* 🔐 **Authentication System** – Secure user login and access
* 🔗 **Link Checking / Awareness Feature** – Helps users identify suspicious links
* 📚 **Cybersecurity Awareness Content** – Educates users on common threats
* 📱 **Mobile-Friendly Interface** – Simple and easy-to-use UI
* ☁️ **Backend Integration** – Supports authentication and data handling

---

## 🚀 How to Run the Mobile App

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/ProtectIt.git
   ```

2. Navigate to the mobile folder:

   ```bash
   cd ProtectIt/mobile
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the app:

   ```bash
   npm start
   ```

5. Run on:

   * Android Emulator
   * iOS Simulator
   * Physical device using Expo Go
